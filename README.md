# Calculus Mastery Workbook

An interactive, self-contained mastery workbook featuring **100 curated exam-level problems and step-by-step solutions** covering Functions, Limits, Continuity, and Derivatives (Sections 1.1 – 3.4), aligned with the standard university Calculus I syllabus.

## ✨ Key Features

- **Crisp Mathematical Typesetting with KaTeX:** Fast and accurate rendering of LaTeX expressions, limits, piecewise functions, and step-by-step derivatives.
- **Tailwind CSS Dark / Light Mode:** Distraction-free academic dark and light themes with smooth transitions.
- **LocalStorage-Powered Progress Tracking:**
  - Mark problems as **Solved** with an interactive progress bar counter
  - **Bookmark (`Review`)** challenging problems for later revision
  - Built-in grid-lined **Scratchpad / Notes** drawer for every problem (automatically saved in your browser)
- **Advanced Filtering & Instant Search:** Filter by chapter, individual section, status (`All`, `Unsolved`, `Solved`, `Review`), or jump directly to the **Special Asymptote Drill (Q61–Q70)**.
- **Print / PDF Export Support:** Dedicated `@media print` stylesheet with clean page breaks and blank workspace boxes for offline paper practice.

## 🚀 Local Setup & Usage

This project is a zero-dependency, single-page web application (`index.html`):

```bash
git clone https://github.com/EnyaliosATH/calculus-mastery-workbook.git
cd calculus-mastery-workbook
```

Open `index.html` directly in any modern web browser or serve the directory with a local static server.
